# SolarisPKN-OS

## Packages

- **[SolarisPKN-Verity](solarispkn-verity/)** — GPL-2.0-only project for distributing BLAKE3 support integrated with upstream Linux dm-verity. **Initial source/package scaffold; no validated kernel module yet.** The folder has its own version, Makefile and Yocto layer structure.

SolarisPKN-OS is planned as a modular operating-system project. Subdirectories may be released as independent packages without splitting them into separate GitHub repositories. Each component has its own licensing and distribution status.
